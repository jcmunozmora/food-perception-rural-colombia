## 📝 Transcripciones

### Contenido de las Transcripciones

Las transcripciones documentan las discusiones grupales sobre:

1. **Significados de "alimentación saludable"**
   - Definiciones locales de "saludable"
   - Heurísticas y reglas de decisión
   - Referencias culturales y familiares

2. **Proceso de co-diseño**
   - Negociaciones sobre qué incluir en el menú ideal
   - Razones para seleccionar ciertos alimentos
   - Discusiones sobre porciones apropiadas

3. **Brecha ideal-práctica**
   - Autoevaluación de alineación (escala 1-5)
   - Explicaciones de la distancia entre ideal y realidad

4. **Barreras y facilitadores**
   - Obstáculos para comer saludable
   - Factores que apoyan elecciones saludables
   - Contextos que facilitan o dificultan

## 🎯 Uso de las Evidencias

### Fotografías

Las fotografías de platos fueron utilizadas para:
- ✅ Documentar visualmente las decisiones grupales
- ✅ Validar la selección de alimentos durante codificación
- ✅ Estimar porciones usando los modelos visuales de referencia
- ✅ Triangular con registros escritos (cuadro de registro)

**Ejemplo de uso:**
```
Grupo: Medellín, 19-30 años, Desayuno
Fotografía → Identificación de alimentos → Estimación de porciones → 
Codificación nutricional → Dataset cuantitativo
```

### Transcripciones

Las transcripciones fueron analizadas mediante:
- ✅ Análisis temático inductivo (NVivo)
- ✅ Doble codificación para confiabilidad
- ✅ Identificación de barreras, significados y heurísticas
- ✅ Saturación temática evaluada iterativamente

**Ejemplo de flujo:**
```
Audio → Transcripción verbatim → Anonimización → 
Codificación temática → Temas principales → Integración con benchmarking
```

## 🔒 Consideraciones Éticas

### Datos Públicos vs. Restringidos

#### ✅ **Disponibles públicamente:**
- Fotografías de platos co-diseñados (sin rostros identificables)
- Estadísticas agregadas de transcripciones
- Citas textuales anonimizadas en artículo y materiales suplementarios

#### ⚠️ **Acceso restringido:**
- Transcripciones completas
- Grabaciones de audio
- Información que podría identificar participantes

**Razón:** Las comunidades rurales pequeñas presentan riesgo de re-identificación incluso con datos anonimizados.

**Disponibilidad:** Outputs cualitativos anonimizados disponibles previa solicitud y aprobación del comité de ética de Universidad EAFIT.

## 🔍 Calidad de los Datos

### Fotografías

- **Resolución:** Alta calidad para identificación de alimentos
- **Etiquetado:** Cada fotografía asociada a región, grupo etario y momento
- **Validación:** Cruzada con cuadro de registro y notas de facilitadores

### Transcripciones

- **Formato:** Verbatim en español
- **Anonimización:** Nombres y lugares identificables removidos/reemplazados
- **Completitud:** Transcripciones completas de todas las sesiones
- **Control de calidad:** Revisión por segundo transcriptor (muestra)
